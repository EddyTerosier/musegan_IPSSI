Étape 5 (Next) — Bouton "Générer" (backend déclenche votre pipeline) + import auto

Cette archive contient UNIQUEMENT des fichiers à AJOUTER / REMPLACER dans votre repo.
Copiez-les à la racine de musegan_IPSSI en conservant l’arborescence.

1) Backend
   - Ajoute POST /api/generate
   - Le endpoint exécute un target Makefile (par défaut: pipeline2), puis importe le run en DB (comme votre bouton import).

2) Front
   - Ajoute un bouton "Générer + importer" qui appelle /api/generate.

Commandes:
- Backend:
  ./.venv/Scripts/python.exe -m pip install -r apps/api/requirements.txt
  ./.venv/Scripts/python.exe -m uvicorn apps.api.main:app --reload --port 8000

- Front:
  cd apps/web
  npm install
  npm run dev

Utilisation:
- Dans l’UI: cliquez "Générer + importer"
- Le backend lance `make pipeline2` (modifiable via payload), puis crée un run en DB.
